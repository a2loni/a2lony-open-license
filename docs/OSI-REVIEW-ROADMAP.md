# OSI review roadmap

This is a preparation roadmap, not an indication that OSI has reviewed or endorsed this project.

1. Preserve an immutable candidate history and record changes between releases.
2. Obtain independent legal review of the English and Spanish texts.
3. Prepare a clear rationale for each permission, condition, patent term, trademark provision, and termination mechanism.
4. Review compatibility and interaction with established open-source licenses.
5. Prepare an English-language submission package and contributor history if required.
6. Submit through OSI's then-current public process and publish the outcome accurately.
7. Do not describe the license as OSI-approved or SPDX-listed unless that status is independently confirmed.
